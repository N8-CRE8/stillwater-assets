Stillwater Verses

Privacy Policy

Last updated 15 August 2026

Stillwater Verses is a one-person publishing project. This policy explains what the project's video publishing tool accesses, what it stores, and how to withdraw its access. It is short because the tool does very little.

Who this covers

The publishing tool has exactly one user, the owner of this project, acting on the single YouTube channel and single Instagram account that they own. The tool is not offered to anyone else. There are no accounts to create, and no other person can sign in to it.

What the tool accesses

The tool uses the YouTube API Services, specifically the videos.insert endpoint, to upload finished video files to the owner's own YouTube channel. Access is granted once by the owner through Google's standard OAuth consent screen, using the youtube.upload scope.

That scope allows uploading only. The tool does not read the channel's videos, comments, subscribers, analytics, or private data, and it does not access any other person's YouTube account or content.

What is stored, and for how long

  • An OAuth refresh token, held in a local configuration file on the owner's own computer, so the tool can upload without signing in again. It is never transmitted anywhere except to Google, and it is deleted when access is revoked.
  • The video ID returned after each upload, kept in the project's own notes so the owner can find the video again.
  • Nothing else. No YouTube user data, no viewer data, no analytics, no personal information about anyone, is collected, stored, or derived.

No data obtained through the YouTube API Services is shared with, sold to, or transmitted to any third party.

Viewers of this website

This site is a set of static pages. It sets no cookies, runs no analytics, embeds no advertising, and loads no third-party scripts, fonts, or trackers. Nothing about visitors is collected. The web host records standard server logs outside this project's control.

Withdrawing access, and deleting data

The owner may revoke this tool's access to their Google account at any time from Google's security settings, at which point the stored refresh token stops working and is deleted. Any request relating to data held by this project can be sent to the contact address below and will be handled within seven days.
