Stillwater Verses

Short daily scripture videos, made for people who feel lost.

Stillwater Verses is a one-person publishing project. Every video is original work: the script is written from scratch, the scripture is quoted from the World English Bible (public domain), the narration is synthesized, and the background footage is licensed stock. Nothing is reposted from another creator.

The videos go out daily to Instagram and to the Stillwater Verses channel on YouTube.

About this publishing tool

The videos are uploaded by a small command line tool that runs on the owner's own computer. It uses the YouTube API Services to upload finished video files to the single YouTube channel owned by the operator of this project.

  • The tool is private. It is not offered to other people, has no accounts, no sign-up, and no user interface beyond the owner's own terminal.
  • It uploads only. It does not read, download, cache, or display anyone else's YouTube content, and it does not collect data about viewers.
  • It acts on one channel only, the operator's own, authorized once through Google's standard OAuth consent screen.
